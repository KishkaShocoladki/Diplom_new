Веб-приложение: анализ влияния структурных вариантов на экспрессию генов

Flask API + React UI: загрузка датасетов, предобработка, обучение/дообучение/переобучение модели,
предсказание и просмотр экспериментов.


ТРЕБОВАНИЯ
----------
- Python 3.10+ (рекомендуется 3.12)
- Node.js 18+ и npm
- PostgreSQL (по умолчанию строка подключения ниже)


УСТАНОВКА
---------

Бэкенд

Из корня репозитория:

    python -m venv venv

    # Windows: venv\Scripts\activate

    pip install -r requirements.txt

Далее необходимо задать БД DATABASE_URL (иначе используется значение по умолчанию из кода):

    postgresql://postgres:postgres@localhost:5432/diplom

Папки для файлов (при отсутствии создаются частично автоматически; пути можно переопределить):

    DATABASE_URL    — строка подключения SQLAlchemy
    DATASETS_DIR    — корень датасетов (raw / preprocessed)
    MODELS_DIR      — сохранённые веса моделей
    ARTIFACTS_DIR   — артефакты предобработки
    PREDICTIONS_DIR — выгрузка предсказаний


Фронтенд

    cd frontend
    npm install

При другом адресе API (не http://localhost:5000/api) создайте frontend/.env:

    REACT_APP_API_BASE=http://localhost:5000/api


ЗАПУСК
------

1. API (из корня репозитория — иначе не разрешится пакет backend):

       python -m backend.app

   API слушает http://0.0.0.0:5000 (в т.ч. http://localhost:5000).

2. Интерфейс:

       cd frontend
       npm start

   Откроется http://localhost:3000.


ДЕМОНСТРАЦИОННЫЙ ПРИМЕР
-----------------------

1. Запуск приложения

   После выполнения команд запуска бэкенда и фронтенда в терминале отображаются
   сообщения об успешном старте серверов на портах 5000 и 3000 соответственно.


2. Загрузка датасетов (первая страница)

   На странице расположена форма с полем выбора TSV-файла и опциональным полем
   названия датасета. После выбора файла доступна кнопка «Загрузить и предобработать».
   В ходе загрузки отображается прогресс-бар с двумя фазами: передача файла (0–50%)
   и серверная предобработка (50–100%), а также лог выполнения.

   В корне проекта находятся тестовые файлы: крупные датасеты с метками (для обучения)
   и небольшие без меток (для предсказания).

   После загрузки в нижней части страницы появляется таблица всех загруженных датасетов
   с указанием количества строк и наличия меток.


3. Обучение (вторая страница)

   Страница содержит форму с селекторами датасета и режима обучения, полями
   гиперпараметров (learning rate, batch size, количество эпох, оптимизатор)
   и опцией Early Stopping. Все поля заполнены значениями по умолчанию.

   Во время обучения на странице в реальном времени строятся графики метрик
   по эпохам: Loss, Accuracy, AUC, F1, Precision, Recall. После завершения
   отображается итоговая таблица метрик.

   Помимо обучения с нуля доступны:

   Дообучение (fine-tune)
       Выбирается соответствующая опция и модель, которую требуется дообучить.
       После завершения, помимо стандартных графиков, отображается таблица
       сравнения метрик текущей версии модели с предыдущей (дельта и процент
       изменения для каждой метрики).

   Переобучение (retrain)
       Аналогично дообучению: выбирается опция и модель. По итогу также
       доступна таблица сравнения с предыдущей версией.


4. Предсказание (третья страница)

   Страница содержит селекторы обученной модели и датасета. После нажатия
   кнопки «Предсказать» запускается фоновая задача.

   По завершении предсказания отображается несколько блоков результатов:

   - Логи и метрики качества (Accuracy, AUC, F1 и др.) — при наличии меток
     в тестовом датасете.

   - Биологическая интерпретация: для каждого структурного варианта перечислены
     затронутые им гены с указанием вероятности патогенного или нейтрального
     воздействия и уровня уверенности модели. Доступны фильтры по категории
     (все / влияют / нейтральные / неопределённые) и поиск по ID СВ или
     названию гена.

   - Таблица предсказаний: для каждой записи указаны тип СВ, хромосома,
     предсказанный класс и уверенность. Столбец «Объяснение» содержит краткий
     вердикт; полное обоснование разворачивается по кнопке «подробнее».

   - Доступен экспорт результатов в форматах PDF, CSV, XLSX. Примеры
     экспортированных файлов находятся в папке проекта.


5. Эксперименты (четвёртая страница)

   На странице отображается список всех запущенных экспериментов (обучения
   и предсказания) с бейджами статуса и типа. При выборе эксперимента
   в правой панели отображаются его детали:

   - Для экспериментов предсказания: таблица результатов с пагинацией.
   - Для обучения с нуля: графики метрик по эпохам.
   - Для дообучения/переобучения: графики метрик и таблица сравнения
     с предыдущей версией модели.

   Из этой страницы также доступен экспорт данных эксперимента.


6. Структурные варианты (пятая страница)

   Страница позволяет анализировать загруженные датасеты без запуска обучения.

   Вкладка «Статистика»: общая сводка по датасету — распределение типов СВ
   (DEL, DUP, INV, INS, BND) по хромосомам, гистограммы длин вариантов,
   статистика по генам и типам генов.

   Вкладка «Данные»: полная таблица всех СВ в датасете с возможностью
   фильтрации по типу СВ и хромосоме, сортировки по столбцам и постраничной
   навигации.
